Kobralink è un server [MCP](https://modelcontextprotocol.io): Claude, ChatGPT o qualsiasi client MCP può sorvegliare e comandare
le stampanti con 56 strumenti (20 di lettura, 36 di controllo). È **disattivato per impostazione predefinita**.

## Configurare

<Steps>
<Step>

### Attivarlo

Un amministratore apre **Impostazioni → MCP (IA)** e attiva il server. Il suo indirizzo è `<tuo indirizzo>/api/mcp`.

</Step>
<Step>

### Collegare il client

<Tabs items={['Claude Code', 'claude.ai, ChatGPT', 'Altri client']}>
<Tab value="Claude Code">

Crea una chiave con l'uso **Assistente IA (MCP)** in [Impostazioni → Chiavi API](/it/docs/administration/api-keys), poi:

```bash
claude mcp add --transport http kobralink http://192.168.1.20:7100/api/mcp --header "Authorization: Bearer kl_..."
```

</Tab>
<Tab value="claude.ai, ChatGPT">

Girano nel cloud, quindi Kobralink ha bisogno di un indirizzo HTTPS pubblico: vedi [HTTPS](/it/docs/administration/https). Poi
aggiungi `https://<dominio>/api/mcp` come connettore e accedi con il tuo account Kobralink (OAuth 2.1).

</Tab>
<Tab value="Altri client">

Qualsiasi client che sappia inviare un header funziona sulla rete locale. Invia `Authorization: Bearer kl_...` con una chiave
MCP.

</Tab>
</Tabs>

</Step>
</Steps>

## Accesso

Ogni chiave o app collegata è in **sola lettura** o di **controllo**. Il ruolo del proprietario viene verificato a ogni
richiesta: un osservatore non controlla mai nulla. Le chiavi MCP coprono sempre tutte le stampanti. Le chiavi si revocano in
**Impostazioni → Chiavi API** e le app in **Impostazioni → MCP (IA)**, con effetto immediato.

## Permessi

Un amministratore imposta ogni strumento su:

| Modalità | Effetto |
| --- | --- |
| Consenti | L'assistente agisce da solo |
| Chiedi | Ricevi una domanda sì/no nella chat, e lo strumento parte solo con un sì |
| Rifiuta | Lo strumento è nascosto |

Gli strumenti sensibili partono da *Chiedi*, gli altri da *Consenti*. Un'app che non sa fare domande riceve un rifiuto; imposta
allora lo strumento su *Consenti* e affidati all'approvazione dell'app stessa. La risposta arriva dall'app IA: Kobralink non può
provare chi ha fatto clic.

## Sicurezza

- Muovere gli assi, caricare filamento, asciugare, avviare una stampa o togliere corrente è **rifiutato mentre la stampante
  stampa o è in pausa**.
- Avviare una stampa richiede `bedIsClear: true`. Il server non può verificare che il piano sia davvero vuoto: tieni attiva
  l'approvazione degli strumenti nel tuo client IA.
- Ogni chiamata di controllo viene scritta nel log con chiave o app, strumento e stampante.
- Le risposte non contengono mai indirizzi della fotocamera, indirizzi IP né credenziali.
- Non esposti: utenti, chiavi, impostazioni, backup, eliminazione di file, G-code grezzo. Carica i file con la dashboard o
  Moonraker.

Queste regole riguardano solo il server MCP. Un programma sulla tua rete può comunque usare le porte Moonraker: proteggile con
una [chiave API](/it/docs/administration/api-keys#lock-the-moonraker-ports).
