指标在控制台端口的 `/api/v1/metrics` 上提供。

## 配置

1. 在[设置 → API 密钥](/zh-cn/docs/administration/api-keys)中，创建一个带 **Prometheus 指标**用途的密钥。
2. 在 Prometheus 中添加该任务。**设置 → Prometheus** 会用你的地址显示它：

```yaml title="prometheus.yml"
scrape_configs:
  - job_name: kobralink
    scheme: http
    metrics_path: /api/v1/metrics
    authorization:
      credentials: kl_…
    static_configs:
      - targets: ['192.168.1.20:7100']
```

绑定到某台打印机的密钥只能看到那台打印机。密钥也可以通过 `X-Api-Key` 请求头发送。

## 指标

所有指标都是 gauge，带 `printer_id` 标签。

| 指标 | 含义 |
| --- | --- |
| `kobralink_printer_info` | 始终为 1，带 `name` 和 `firmware` 标签 |
| `kobralink_printer_connected` | MQTT 会话正常时为 1 |
| `kobralink_printer_state` | 当前状态为 1，状态在 `state` 标签中 |
| `kobralink_nozzle_temperature_celsius`、`kobralink_nozzle_target_celsius` | 喷嘴 |
| `kobralink_bed_temperature_celsius`、`kobralink_bed_target_celsius` | 热床 |
| `kobralink_fan_speed_ratio` | 模型风扇，0–1 |
| `kobralink_print_speed_mode` | 1 静音、2 标准、3 运动 |
| `kobralink_print_progress_ratio` | 进度，0–1 |
| `kobralink_print_duration_seconds` | 已用时间 |
| `kobralink_print_remaining_seconds` | 预计剩余时间 |
| `kobralink_print_layer`、`kobralink_print_layers_total` | 层 |
| `kobralink_printer_error_code` | 最近的错误代码，没有时为 0 |
| `kobralink_light_on` | 灯亮时为 1 |
| `kobralink_storage_used_bytes`、`kobralink_storage_total_bytes` | 打印机存储 |
| `kobralink_ace_humidity_percent` | ACE 湿度，带 `ace` 标签 |
| `kobralink_ace_temperature_celsius` | ACE 温度，带 `ace` 标签 |
| `kobralink_ace_drying` | ACE 烘干时为 1，带 `ace` 标签 |

没有打印时，打印相关指标为 0。

## 显示打印机名称

```text
kobralink_nozzle_temperature_celsius
  * on (printer_id) group_left (name) kobralink_printer_info
```
