Kobralink es un servidor [MCP](https://modelcontextprotocol.io): Claude, ChatGPT o cualquier cliente MCP puede vigilar y
controlar las impresoras con 56 herramientas (20 de lectura, 36 de control). Está **desactivado por defecto**.

## Configurar

<Steps>
<Step>

### Activarlo

Un administrador abre **Ajustes → MCP (IA)** y activa el servidor. Su dirección es `<tu dirección>/api/mcp`.

</Step>
<Step>

### Conectar el cliente

<Tabs items={['Claude Code', 'claude.ai, ChatGPT', 'Otros clientes']}>
<Tab value="Claude Code">

Crea una clave con el uso **Asistente de IA (MCP)** en [Ajustes → Claves API](/es/docs/administration/api-keys) y luego:

```bash
claude mcp add --transport http kobralink http://192.168.1.20:7100/api/mcp --header "Authorization: Bearer kl_..."
```

</Tab>
<Tab value="claude.ai, ChatGPT">

Funcionan en la nube, así que Kobralink necesita una dirección HTTPS pública: consulta [HTTPS](/es/docs/administration/https).
Luego añade `https://<dominio>/api/mcp` como conector e inicia sesión con tu cuenta de Kobralink (OAuth 2.1).

</Tab>
<Tab value="Otros clientes">

Cualquier cliente que pueda enviar una cabecera funciona en la red local. Envía `Authorization: Bearer kl_...` con una clave
MCP.

</Tab>
</Tabs>

</Step>
</Steps>

## Acceso

Cada clave o aplicación conectada es de **solo lectura** o de **control**. El rol de su propietario se comprueba en cada
petición: un observador nunca controla nada. Las claves MCP cubren siempre todas las impresoras. Las claves se revocan en
**Ajustes → Claves API** y las aplicaciones en **Ajustes → MCP (IA)**, con efecto inmediato.

## Permisos

Un administrador ajusta cada herramienta en:

| Modo | Efecto |
| --- | --- |
| Permitir | El asistente actúa solo |
| Preguntar | Recibes una pregunta de sí/no en el chat, y la herramienta solo se ejecuta con un sí |
| Rechazar | La herramienta queda oculta |

Las herramientas sensibles empiezan en *Preguntar* y las demás en *Permitir*. Una aplicación que no puede preguntar recibe un
rechazo; pon entonces la herramienta en *Permitir* y confía en la aprobación de la propia aplicación. La respuesta viene de la
aplicación de IA: Kobralink no puede demostrar quién hizo clic.

## Seguridad

- Mover ejes, cargar filamento, secar, iniciar una impresión o cortar la corriente se **rechaza mientras la impresora imprime o
  está en pausa**.
- Iniciar una impresión exige `bedIsClear: true`. El servidor no puede comprobar que la cama esté realmente vacía, así que
  mantén activa la aprobación de herramientas en tu cliente de IA.
- Cada llamada de control se escribe en el registro con la clave o la aplicación, la herramienta y la impresora.
- Las respuestas nunca contienen direcciones de cámara, direcciones IP ni credenciales.
- No expuesto: usuarios, claves, ajustes, copias de seguridad, borrado de archivos, G-code en bruto. Sube los archivos con el
  panel o Moonraker.

Estas reglas solo cubren el servidor MCP. Un programa de tu red puede seguir usando los puertos Moonraker: protégelos con una
[clave API](/es/docs/administration/api-keys#lock-the-moonraker-ports).
