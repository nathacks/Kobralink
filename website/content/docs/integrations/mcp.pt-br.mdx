O Kobralink é um servidor [MCP](https://modelcontextprotocol.io): Claude, ChatGPT ou qualquer cliente MCP pode acompanhar e
controlar as impressoras com 56 ferramentas (20 de leitura, 36 de controle). Ele vem **desativado por padrão**.

## Configurar

<Steps>
<Step>

### Ativar

Um administrador abre **Configurações → MCP (IA)** e ativa o servidor. O endereço é `<seu endereço>/api/mcp`.

</Step>
<Step>

### Conectar o cliente

<Tabs items={['Claude Code', 'claude.ai, ChatGPT', 'Outros clientes']}>
<Tab value="Claude Code">

Crie uma chave com o uso **Assistente de IA (MCP)** em [Configurações → Chaves de API](/pt-br/docs/administration/api-keys) e depois:

```bash
claude mcp add --transport http kobralink http://192.168.1.20:7100/api/mcp --header "Authorization: Bearer kl_..."
```

</Tab>
<Tab value="claude.ai, ChatGPT">

Eles rodam na nuvem, então o Kobralink precisa de um endereço HTTPS público: veja [HTTPS](/pt-br/docs/administration/https). Depois
adicione `https://<domínio>/api/mcp` como conector e entre com sua conta do Kobralink (OAuth 2.1).

</Tab>
<Tab value="Outros clientes">

Qualquer cliente que envie um cabeçalho funciona na rede local. Envie `Authorization: Bearer kl_...` com uma chave MCP.

</Tab>
</Tabs>

</Step>
</Steps>

## Acesso

Cada chave ou aplicativo conectado é **somente leitura** ou de **controle**. A função do dono é verificada em cada requisição: um
visualizador nunca controla nada. Chaves MCP sempre cobrem todas as impressoras. Chaves são revogadas em
**Configurações → Chaves de API** e aplicativos em **Configurações → MCP (IA)**, com efeito imediato.

## Permissões

Um administrador define cada ferramenta como:

| Modo | Efeito |
| --- | --- |
| Permitir | O assistente age sozinho |
| Perguntar | Você recebe uma pergunta de sim/não no chat, e a ferramenta só roda com sim |
| Recusar | A ferramenta fica oculta |

As ferramentas sensíveis começam em *Perguntar*, as demais em *Permitir*. Um aplicativo que não consegue perguntar recebe uma
recusa; nesse caso, mude a ferramenta para *Permitir* e conte com a aprovação do próprio aplicativo. A resposta vem do aplicativo
de IA: o Kobralink não consegue provar quem clicou.

## Segurança

- Mover eixos, carregar filamento, secar, iniciar uma impressão ou cortar a energia é **recusado enquanto a impressora imprime ou
  está pausada**.
- Iniciar uma impressão exige `bedIsClear: true`. O servidor não consegue verificar se a mesa está realmente vazia, então mantenha
  a aprovação de ferramentas ligada no seu cliente de IA.
- Cada chamada de controle é registrada no log com a chave ou o aplicativo, a ferramenta e a impressora.
- As respostas nunca contêm endereços de câmera, endereços IP nem credenciais.
- Não expostos: usuários, chaves, configurações, backups, exclusão de arquivos, G-code bruto. Envie arquivos pelo painel ou pelo
  Moonraker.

Essas regras valem só para o servidor MCP. Um programa na sua rede ainda pode usar as portas Moonraker: tranque-as com uma
[chave de API](/pt-br/docs/administration/api-keys#lock-the-moonraker-ports).
