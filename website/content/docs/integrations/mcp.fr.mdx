Kobralink est un serveur [MCP](https://modelcontextprotocol.io) : Claude, ChatGPT ou n'importe quel client MCP peut surveiller
et piloter les imprimantes grâce à 56 outils (20 en lecture, 36 de contrôle). Il est **désactivé par défaut**.

## Configurer

<Steps>
<Step>

### L'activer

Un administrateur ouvre **Paramètres → MCP (IA)** et active le serveur. Son adresse est `<votre adresse>/api/mcp`.

</Step>
<Step>

### Connecter le client

<Tabs items={['Claude Code', 'claude.ai, ChatGPT', 'Autres clients']}>
<Tab value="Claude Code">

Créez une clé avec l'usage **Assistant IA (MCP)** dans [Paramètres → Clés API](/fr/docs/administration/api-keys), puis :

```bash
claude mcp add --transport http kobralink http://192.168.1.20:7100/api/mcp --header "Authorization: Bearer kl_..."
```

</Tab>
<Tab value="claude.ai, ChatGPT">

Ils tournent dans le cloud : Kobralink a besoin d'une adresse HTTPS publique, voir [HTTPS](/fr/docs/administration/https).
Ajoutez ensuite `https://<domaine>/api/mcp` comme connecteur et connectez-vous avec votre compte Kobralink (OAuth 2.1).

</Tab>
<Tab value="Autres clients">

Tout client capable d'envoyer un en-tête fonctionne sur le réseau local. Envoyez `Authorization: Bearer kl_...` avec une clé
MCP.

</Tab>
</Tabs>

</Step>
</Steps>

## Accès

Chaque clé ou application connectée est en **lecture seule** ou en **contrôle**. Le rôle de son propriétaire est vérifié à
chaque requête : un compte en lecture seule ne contrôle jamais rien. Les clés MCP couvrent toujours toutes les imprimantes.
Les clés se révoquent dans **Paramètres → Clés API** et les applications dans **Paramètres → MCP (IA)**, avec effet immédiat.

## Autorisations

Un administrateur règle chaque outil sur :

| Mode | Effet |
| --- | --- |
| Autoriser | L'assistant agit seul |
| Demander | Vous recevez une question oui/non dans la conversation, et l'outil ne s'exécute que sur oui |
| Refuser | L'outil est masqué |

Les outils sensibles démarrent sur *Demander*, les autres sur *Autoriser*. Une application qui ne sait pas poser de question
reçoit un refus ; passez alors l'outil sur *Autoriser* et comptez sur la validation propre à l'application. La réponse vient
de l'application d'IA : Kobralink ne peut pas prouver qui a cliqué.

## Sécurité

- Déplacer les axes, charger du filament, sécher, lancer une impression ou couper l'alimentation est **refusé pendant que
  l'imprimante imprime ou est en pause**.
- Lancer une impression exige `bedIsClear: true`. Le serveur ne peut pas vérifier que le plateau est vraiment vide : gardez la
  validation des outils active dans votre client IA.
- Chaque appel de contrôle est écrit dans le journal avec la clé ou l'application, l'outil et l'imprimante.
- Les réponses ne contiennent jamais d'adresses de caméra, d'adresses IP ni d'identifiants.
- Non exposé : utilisateurs, clés, paramètres, sauvegardes, suppression de fichiers, G-code brut. Envoyez les fichiers avec le
  tableau de bord ou Moonraker.

Ces règles ne concernent que le serveur MCP. Un programme de votre réseau peut toujours utiliser les ports Moonraker :
verrouillez-les avec une [clé API](/fr/docs/administration/api-keys#lock-the-moonraker-ports).
