Kobralink ist ein [MCP](https://modelcontextprotocol.io)-Server: Claude, ChatGPT oder jeder MCP-Client kann die Drucker über
56 Werkzeuge überwachen und steuern (20 zum Lesen, 36 zum Steuern). Er ist **standardmäßig aus**.

## Einrichten

<Steps>
<Step>

### Einschalten

Ein Administrator öffnet **Einstellungen → MCP (KI)** und aktiviert den Server. Seine Adresse ist `<ihre adresse>/api/mcp`.

</Step>
<Step>

### Den Client verbinden

<Tabs items={['Claude Code', 'claude.ai, ChatGPT', 'Andere Clients']}>
<Tab value="Claude Code">

Legen Sie unter [Einstellungen → API-Schlüssel](/de/docs/administration/api-keys) einen Schlüssel mit der Verwendung
**KI-Assistent (MCP)** an, dann:

```bash
claude mcp add --transport http kobralink http://192.168.1.20:7100/api/mcp --header "Authorization: Bearer kl_..."
```

</Tab>
<Tab value="claude.ai, ChatGPT">

Sie laufen in der Cloud, daher braucht Kobralink eine öffentliche HTTPS-Adresse: siehe [HTTPS](/de/docs/administration/https).
Fügen Sie dann `https://<domain>/api/mcp` als Connector hinzu und melden Sie sich mit Ihrem Kobralink-Konto an (OAuth 2.1).

</Tab>
<Tab value="Andere Clients">

Jeder Client, der einen Header senden kann, funktioniert im lokalen Netzwerk. Senden Sie `Authorization: Bearer kl_...` mit
einem MCP-Schlüssel.

</Tab>
</Tabs>

</Step>
</Steps>

## Zugriff

Jeder Schlüssel und jede verbundene App ist **nur lesend** oder **steuernd**. Die Rolle des Besitzers wird bei jeder Anfrage
geprüft: Ein Betrachter steuert nie etwas. MCP-Schlüssel gelten immer für alle Drucker. Schlüssel widerrufen Sie unter
**Einstellungen → API-Schlüssel**, Apps unter **Einstellungen → MCP (KI)**, jeweils mit sofortiger Wirkung.

## Berechtigungen

Ein Administrator stellt jedes Werkzeug ein auf:

| Modus | Wirkung |
| --- | --- |
| Erlauben | Der Assistent handelt selbstständig |
| Fragen | Sie erhalten im Chat eine Ja/Nein-Frage, und das Werkzeug läuft nur bei Ja |
| Ablehnen | Das Werkzeug ist ausgeblendet |

Heikle Werkzeuge starten auf *Fragen*, die anderen auf *Erlauben*. Eine App, die nicht fragen kann, erhält eine Ablehnung;
stellen Sie das Werkzeug dann auf *Erlauben* und verlassen Sie sich auf die Freigabe der App selbst. Die Antwort kommt von
der KI-App: Kobralink kann nicht nachweisen, wer geklickt hat.

## Sicherheit

- Achsen bewegen, Filament laden, trocknen, einen Druck starten oder den Strom abschalten wird **abgelehnt, solange der
  Drucker druckt oder pausiert ist**.
- Ein Druckstart verlangt `bedIsClear: true`. Der Server kann nicht prüfen, ob das Bett wirklich leer ist, lassen Sie die
  Werkzeugfreigabe in Ihrem KI-Client also an.
- Jeder Steueraufruf wird mit Schlüssel oder App, Werkzeug und Drucker protokolliert.
- Antworten enthalten nie Kameraadressen, IP-Adressen oder Zugangsdaten.
- Nicht verfügbar: Benutzer, Schlüssel, Einstellungen, Sicherungen, Löschen von Dateien, roher G-Code. Laden Sie Dateien über
  das Dashboard oder Moonraker hoch.

Diese Regeln gelten nur für den MCP-Server. Ein Programm in Ihrem Netzwerk kann die Moonraker-Ports weiterhin nutzen: Sichern
Sie sie mit einem [API-Schlüssel](/de/docs/administration/api-keys#lock-the-moonraker-ports) ab.
