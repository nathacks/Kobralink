| Seite | Inhalt |

| Benachrichtigungen | [Kanäle und Ereignisse](/de/docs/guide/notifications) |
| KI-Erkennung | [Modell, Aktion, Empfindlichkeit](/de/docs/guide/failure-detection) |
| Integrationen | [Spoolman](/de/docs/integrations/spoolman), [Home Assistant](/de/docs/integrations/home-assistant) |
| OrcaSlicer | [Adressen](/de/docs/getting-started/orcaslicer), API-Schlüssel-Pflicht |
| MCP (KI) | [Server, Werkzeuge, verbundene Apps](/de/docs/integrations/mcp) |

## Allgemein

| Einstellung | Standard | Wirkung |
| --- | --- | --- |
| Design, Sprache der Oberfläche | | In diesem Browser gespeichert |
| Sprache der Benachrichtigungen | Französisch | Sprache der Nachrichten, die die Bridge sendet |
| Währung | `EUR` | ISO-Code für die Anzeige der Kosten |
| Standard-Filamentpreis | 0 | Pro kg. 0 = ohne Preis |
| Strompreis | 0 | Pro kWh. 0 ignoriert die Energie |
| Durchschnittliche Leistung des Druckers | 0 | In Watt, wenn der Drucker keine eigene hat |
| Kobralink-Adresse | | Ziel der Links in Benachrichtigungen |
| Nach Updates suchen | an | Fragt GitHub nach der neuesten Version |
| Ausführliches HTTP-Protokoll | aus | Protokolliert jede Anfrage |
