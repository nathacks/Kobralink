| Ruolo | Può |
| --- | --- |
| Amministratore | Tutto |
| Operatore | Comandare le stampanti, modificare le impostazioni, creare chiavi API |
| Osservatore | Solo consultare |

Solo gli amministratori possono gestire gli utenti, attivare o disattivare il server MCP, cambiare i permessi dei suoi strumenti,
scaricare o ripristinare un backup e riavviare Kobralink.

Un osservatore può comunque attivare le notifiche push sul proprio dispositivo e disconnettere le app IA che ha autorizzato.

## Gestire gli account

Il primo account è creato dalla procedura di configurazione ed è amministratore. Poi la registrazione è chiusa. Gli
amministratori creano gli altri account in **Impostazioni → Utenti**, con una password di almeno 8 caratteri, e lì possono
cambiare un ruolo o una password.

- Deve restare sempre almeno un amministratore.
- Non puoi togliere il tuo ruolo di amministratore né eliminare il tuo account.
- Eliminare un utente chiude subito le sue sessioni.

Le sessioni durano 30 giorni e si rinnovano finché vengono usate.

<Callout type="info">Dai account solo a persone di fiducia, anche in sola lettura.</Callout>
