## Generale

| Impostazione | Predefinito | Effetto |
| --- | --- | --- |
| Tema, lingua dell'interfaccia | | Salvati in questo browser |
| Lingua delle notifiche | Francese | Lingua dei messaggi inviati dal bridge |
| Valuta | `EUR` | Codice ISO usato per mostrare i costi |
| Prezzo del filamento predefinito | 0 | Al kg. 0 = senza prezzo |
| Prezzo dell'elettricità | 0 | Al kWh. 0 ignora l'energia |
| Potenza media della stampante | 0 | In watt, se la stampante non ha la sua |
| Indirizzo di Kobralink | | Destinazione dei link nelle notifiche |
| Controlla aggiornamenti | attivo | Chiede a GitHub l'ultima versione |
| Log HTTP dettagliato | disattivato | Registra ogni richiesta |
