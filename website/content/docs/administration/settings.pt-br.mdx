## Geral

| Configuração | Padrão | Efeito |
| --- | --- | --- |
| Tema, idioma da interface | | Salvos neste navegador |
| Idioma das notificações | Francês | Idioma das mensagens enviadas pela bridge |
| Moeda | `EUR` | Código ISO usado para mostrar os custos |
| Preço padrão do filamento | 0 | Por kg. 0 = sem preço |
| Preço da energia | 0 | Por kWh. 0 ignora a energia |
| Potência média da impressora | 0 | Em watts, quando a impressora não tem a sua |
| Endereço do Kobralink | | Destino dos links nas notificações |
| Verificar atualizações | ativado | Pergunta ao GitHub pela versão mais recente |
| Log HTTP detalhado | desativado | Registra cada requisição |
