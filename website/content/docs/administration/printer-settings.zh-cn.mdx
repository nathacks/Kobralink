---
title: 打印机设置
description: 一台打印机的所有选项。
---

打开一台打印机，然后点击**设置**。

## 档案 [#profile]

| 设置 | 作用 |
| --- | --- |
| 位置 | 自由文本 |
| 标签 | 最多 20 个。用于给打印机分组，以指定队列任务和自动化的目标 |
| 已安装的喷嘴 | 为其他喷嘴切片的文件不会发往这台打印机 |
| 平均功率 | 在能耗成本中替代默认值 |
| 打印尺寸 | X、Y、Z，单位毫米。留空：使用型号[规格](/zh-cn/docs/reference/printers)。用于打印队列和 Moonraker |

Anycubic 公布了该型号的规格时，会显示官方规格。

## 连接

| 设置 | 作用 |
| --- | --- |
| 名称、IP 地址 | |
| Moonraker 端口 | 1024 到 65535，唯一 |
| 刷新凭据 | 重新从打印机读取凭据 |
| 重启 MQTT 会话 | 重新连接 |
| 断开连接 | 关闭会话，直到重新连接。便于让其他局域网客户端接入 |

## 打印 [#printing]

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 自动调平 | 开 | 每次打印前 |
| 振动补偿 | 关 | 每次打印前 |
| 流量校准 | 开 | 每次打印前 |
| 摄像头常开 | 开 | 保持摄像头运行 |
| 打印开始时启动摄像头 | 关 | 打印开始时启动画面 |
| 默认 AMS 槽位 | auto | *auto* 使用 G-code 需要的所有槽位 |
| 网页上传时警告 | 开 | 打印从浏览器上传的文件前要求确认 |
| 上传后弹窗 | 开 | 上传后打开打印窗口。关闭则直接开始打印 |
| 自动开始下一个文件 | 关 | 见[队列](/zh-cn/docs/guide/queue#automatic-start) |
| 确认热床已清空 | 开 | 见[队列](/zh-cn/docs/guide/queue#clearing-the-bed) |
| 开始前等待 | 15 秒 | 0 到 3600 秒 |
| 灯光触发 | 关 | 见[队列](/zh-cn/docs/guide/queue#light-trigger) |
| 打印后从打印机删除 | 关 | 释放打印机存储 |
| 轮询间隔 | 3 秒 | 两次状态请求之间 1 到 60 秒 |

## 延时摄影

| 设置 | 默认 |
| --- | --- |
| 录制延时摄影 | 关 |
| 每秒帧数 | 15（5 到 60） |

## 失败检测

| 设置 | 默认 |
| --- | --- |
| 监控此打印机 | 开 |

在全局启用[检测](/zh-cn/docs/guide/failure-detection)后生效。

## 警报 [#alerts]

设为 0 即关闭该警报。

| 警报 | 默认 |
| --- | --- |
| 喷嘴最高温度 | 300 °C |
| 热床最高温度 | 110 °C |
| 离线时长 | 0 分钟（关） |
| 料卷快用完 | 0 g（关） |

## 插座（Home Assistant）

配置好 [Home Assistant API](/zh-cn/docs/integrations/home-assistant#smart-plug-and-energy) 后显示：插座开关和电量计。

## 可见品牌

筛选每个槽位可选的 OrcaSlicer 配置。不选择则显示所有品牌。你导入的配置始终显示。

## 删除打印机

保存在 Kobralink 中的 G-code 文件会保留。
