## Général

| Paramètre | Défaut | Effet |
| --- | --- | --- |
| Thème, langue de l'interface | | Gardés dans ce navigateur |
| Langue des notifications | Français | Langue des messages envoyés par le bridge |
| Devise | `EUR` | Code ISO utilisé pour afficher les coûts |
| Prix filament par défaut | 0 | Au kg. 0 = non chiffré |
| Prix de l'électricité | 0 | Au kWh. 0 ignore l'énergie |
| Puissance moyenne de l'imprimante | 0 | En watts, utilisée quand l'imprimante n'en a pas |
| Adresse de Kobralink | | Cible des liens dans les notifications |
| Vérifier les mises à jour | activé | Demande à GitHub la dernière version |
| Journal HTTP détaillé | désactivé | Journalise chaque requête |
