| 角色 | 可以 |
| --- | --- |
| 管理员 | 所有操作 |
| 操作员 | 控制打印机、修改设置、创建 API 密钥 |
| 观察者 | 只能查看 |

只有管理员可以管理用户、开启或关闭 MCP 服务器、修改其工具权限、下载或恢复备份，以及重启 Kobralink。

观察者仍可以在自己的设备上开启推送通知，并断开自己授权的 AI 应用。

## 管理账号

第一个账号由设置向导创建，为管理员。之后注册即关闭。管理员在**设置 → 用户**中创建其他账号（密码至少 8 个字符），并可在那里修改
角色或密码。

- 至少要保留一名管理员。
- 你不能移除自己的管理员角色，也不能删除自己的账号。
- 删除用户会立即关闭其所有会话。

会话有效期 30 天，使用期间会自动续期。

<Callout type="info">只把账号给你信任的人，只读账号也一样。</Callout>
