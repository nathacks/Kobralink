El campo de búsqueda de arriba encuentra cualquier opción, incluidas las de las impresoras.

| Página | Contenido |
| --- | --- |
| General | Tema, idioma de la interfaz, moneda, costes, dirección, actualizaciones |
| Notificaciones | [Canales y eventos](/es/docs/guide/notifications) |
| Detección IA | [Modelo, acción, sensibilidad](/es/docs/guide/failure-detection) |
| Integraciones | [Spoolman](/es/docs/integrations/spoolman), [Home Assistant](/es/docs/integrations/home-assistant) |
| OrcaSlicer | [Direcciones](/es/docs/getting-started/orcaslicer), exigencia de clave API |
| MCP (IA) | [Servidor, herramientas, aplicaciones conectadas](/es/docs/integrations/mcp) |
| Claves API | [Claves](/es/docs/administration/api-keys) |
| Prometheus | [Dirección de las métricas](/es/docs/integrations/prometheus) |
| Macros | [Macros](/es/docs/guide/macros) |
| Usuarios | [Cuentas](/es/docs/administration/users), solo administradores |
| Sistema | Versión, tiempo activo, [copia de seguridad](/es/docs/administration/backup), reinicio |
| Registros | Registro en directo, filtro por nivel y origen, descarga |

## General

| Ajuste | Por defecto | Efecto |
| --- | --- | --- |
| Tema, idioma de la interfaz | | Se guardan en este navegador |
| Idioma de las notificaciones | Francés | Idioma de los mensajes que envía el bridge |
| Moneda | `EUR` | Código ISO usado para mostrar los costes |
| Precio de filamento por defecto | 0 | Por kg. 0 = sin precio |
| Precio de la electricidad | 0 | Por kWh. 0 ignora la energía |
| Potencia media de la impresora | 0 | En vatios, si la impresora no tiene la suya |
| Dirección de Kobralink | | Destino de los enlaces de las notificaciones |
| Buscar actualizaciones | activado | Pregunta a GitHub por la última versión |
| Registro HTTP detallado | desactivado | Registra cada petición |
