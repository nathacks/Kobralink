## Docker

Set these in `.env`, next to the compose file.

| Variable | Default | Role |
| --- | --- | --- |
| `BETTER_AUTH_URL` | `http://localhost:7100` | **Set it**: the URL used by the browser |
| `BETTER_AUTH_SECRET` | generated in `/data` | Session secret (`openssl rand -base64 32`) |
| `KOBRALINK_BIND` | `0.0.0.0` | Host interface. `127.0.0.1` behind a reverse proxy |
| `KOBRALINK_PORT` | `7100` | Dashboard port on the host |
| `KOBRALINK_EXTRA_ORIGINS` | | Other allowed origins, comma-separated |
| `KOBRALINK_TRUSTED_PROXIES` | | Proxy IPs or CIDRs, comma-separated |
| `KOBRALINK_IP_HEADERS` | | Header with the client IP, set by the proxy |
| `KOBRALINK_DOMAIN` | | Domain for `docker-compose.https.yml` |
| `KOBRALINK_IMAGE` | `nathacks/kobralink:latest` | Image name, used by `docker-compose.yml` (build from source) only |
| `TZ` | `UTC` | Time zone of automations and daily statistics |

## Server process

Already set in the Docker image and the desktop app. Useful when running from source.

| Variable | Default | Role |
| --- | --- | --- |
| `KOBRALINK_DATA_DIR` | `<repo>/data` | Data directory |
| `DATABASE_URL` | `file:<data>/kobralink.db` | Database |
| `KOBRALINK_WEB_DIR` | `apps/web/dist` | Dashboard build to serve |
| `KOBRALINK_CERTS_DIR` | `apps/api/certs` | `anycubic_slicer.crt` and `.key` |
| `KOBRALINK_FFMPEG` | bundled, else `PATH` | ffmpeg binary |
| `KOBRALINK_VERSION` | `package.json` | Reported version |
| `KOBRALINK_UPDATE_REPO` | `NatHacks/Kobralink` | Repository polled for updates |
| `KOBRALINK_DETECTION_MODEL_URL` | Obico's model | Address of the detection model |

## Desktop app

| Variable | Role |
| --- | --- |
| `KOBRALINK_PORT` | Port of the local bridge |
| `KOBRALINK_URL` | Opens this bridge without starting a local one |
