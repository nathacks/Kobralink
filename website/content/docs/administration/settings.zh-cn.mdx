| AI 检测 | [模型、操作、灵敏度](/zh-cn/docs/guide/failure-detection) |
| 集成 | [Spoolman](/zh-cn/docs/integrations/spoolman)、[Home Assistant](/zh-cn/docs/integrations/home-assistant) |

## 常规

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 主题、界面语言 | | 保存在此浏览器中 |
| 通知语言 | 法语 | 桥接程序发送消息使用的语言 |
| 货币 | `EUR` | 显示成本使用的 ISO 代码 |
| 默认耗材价格 | 0 | 每 kg。0 表示不计价 |
| 电价 | 0 | 每 kWh。0 表示忽略能耗 |
| 打印机平均功率 | 0 | 单位瓦，打印机未设置自身功率时使用 |
| Kobralink 地址 | | 通知中链接的目标 |
| 检查更新 | 开 | 向 GitHub 查询最新版本 |
| 详细 HTTP 日志 | 关 | 记录每个请求 |
