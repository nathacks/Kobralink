| Ordner | Rolle |

| `packages/i18n` | Paraglide-Nachrichten in 7 Sprachen |
| `infra` | Dockerfile und Compose-Dateien |
| `website` | Diese Dokumentation |

## Grundideen

**Eine Bridge pro Drucker.** Eine `PrinterBridge` hält die MQTT-Sitzung, den Live-Zustand, die Abfrageschleife und die
Befehle. `BridgeRegistry` legt für jeden Drucker der Datenbank eine an.

**Ein Moonraker-Server pro Drucker.** Jeder ist eine eigene Nest-Anwendung auf einem eigenen Port. Er übersetzt den
Live-Zustand in Klipper-Objekte.

**Verträge an einem Ort.** Jeder Body von `/api/v1` hat ein Zod-Schema in `packages/shared`, geprüft von der API und typisiert
im Dashboard.

**Live-Updates.** Das Dashboard empfängt Ereignisse per SSE und schreibt sie in den Query-Cache.

**Ein Kameraprozess pro Drucker.** Ein einziges ffmpeg versorgt Dashboard, Moonraker-Clients, Zeitraffer und Erkennung.

**Migrationen beim Start.** Die API wendet beim Start ausstehende Prisma-Migrationen an.
