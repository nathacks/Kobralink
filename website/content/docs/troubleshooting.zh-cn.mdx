---
title: 故障排除
description: 常见问题及处理方法。
---

先查看**设置 → 日志**：按打印机筛选，需要分享时再下载日志。发布前请删除你想保密的 IP 地址和文件名。

## 打印机一直离线

| 消息 | 原因 | 解决办法 |
| --- | --- | --- |
| MQTT 端口已关闭 | 局域网模式未开启 | 在打印机设置中开启 |
| MQTT 凭据被拒绝 | 凭据已更改 | 打印机设置 → **刷新凭据** |
| 网络上无法访问打印机 | IP 错误、打印机关机、不在同一网络 | 检查 IP；在路由器中保留它 |
| 连接数达到上限（代码 19002） | 有其他局域网客户端已连接 | 关闭 Anycubic Slicer Next、Home Assistant 集成… |
| 已手动断开 | 你关闭了会话 | 重新连接 |

打印机**只接受一个局域网会话**：两个 Kobralink 实例连接同一台打印机会互相踢掉。

## 无法登录

`BETTER_AUTH_URL` 必须是你在浏览器中输入的地址，包括协议和端口。把其他地址加入 `KOBRALINK_EXTRA_ORIGINS`，然后用
`docker compose up -d` 重新创建容器。使用 HTTPS 地址时，无法通过普通 HTTP 登录。

## OrcaSlicer 无法连接

- 检查主机是否包含 `http://` 和打印机端口。
- 检查 Kobralink 是否在运行，防火墙是否放行该端口。
- 如果要求密钥，请粘贴一个带 Moonraker 用途的密钥。
- 从第 17 台打印机起，请[发布更多端口](/zh-cn/docs/getting-started/docker#ports)。

## *发送并打印*后没有开始打印

打印窗口正在控制台中等待。请在那里确认，或在打印机设置中关闭**上传后弹窗**。

## 上传被拒绝

| 消息 | 解决办法 |
| --- | --- |
| 打印机空间不足 | 在**打印机**页签中删除文件 |
| 打印机拒绝了文件名或文件类型 | 使用以 `.gcode` 结尾的简单名称 |
| 打印机未提供上传 URL | 重新连接打印机 |

## 看不到摄像头

- *未连接摄像头*：打印机报告没有接入摄像头。
- *429*：另一个客户端正在使用画面。关闭它并重启画面。
- 自定义安装时，请检查 ffmpeg 是否可用。

## 队列不动

查看任务上显示的原因，参见[任务为什么在等待](/zh-cn/docs/guide/queue#why-an-item-waits)。最常见的是热床尚未确认清空。

## 自动化在错误的时间运行

它们使用服务器时区，显示在**设置 → 系统**中。请在 `.env` 中设置 `TZ`。

## 桌面应用无法启动桥接程序

错误页面可以打开日志。常见原因是 7100 端口已被另一个实例占用。

## TLS 握手被拒绝

Anycubic 固件更新后，内置证书可能已过时。请提交 [issue](https://github.com/NatHacks/Kobralink/issues)，或提取新的证书：参见
[证书](/zh-cn/docs/development/setup#certificates)。
