---
title: 自动化
description: 在发生某件事时作用于打印机的规则。
---

一条规则规定**何时**发生某事、作用于**哪些**打印机、**然后**做什么。在**自动化**页面中管理。

## 触发条件

| 触发条件 | 何时 |
| --- | --- |
| 打印完成 | 打印正常结束 |
| 打印被取消或失败 | 打印提前结束 |
| 热床已清理 | 你确认了，或使用了灯光触发 |
| 料卷快用完 | 打印机的料卷不足警报触发 |
| 每天定时 | 服务器时间，`HH:MM` |

料卷触发需要在打印机的[警报](/zh-cn/docs/administration/printer-settings#alerts)中设置阈值。定时触发使用服务器时区，Docker 中由 `TZ`
设置。

## 目标

所有打印机、一台打印机，或带有所有指定标签的打印机。

## 动作

一条规则有 1 到 10 个动作，按顺序执行：

| 动作 | 说明 |
| --- | --- |
| 运行宏 | |
| 灯光 | 开或关 |
| 耗材（ACE） | 为某个槽位进料或退料；在没有 ACE 的打印机上会失败 |
| 智能插座 | 开或关 |
| 通知 | 最多 200 个字符的消息 |
| 等待 | 1 到 3600 秒 |

如果某个动作失败，规则就在那里停止。错误会显示在规则上。

打印正在进行或暂停时，**关闭插座**会被拒绝。否则 Kobralink 会等喷嘴降到 50 °C 以下，30 分钟后放弃。

## 示例

| 目标 | 何时 | 然后 |
| --- | --- | --- |
| 打印后断电 | 打印完成 | 智能插座：关 |
| 夜间关灯 | 每天 23:00 | 灯光：关 |
| 提醒工作间 | 打印被取消或失败 | 通知：“检查打印机” |

**立即运行**会在一台打印机上测试规则。规则会显示上次运行情况。
