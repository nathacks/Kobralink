---
title: Wartung
description: Vorbeugende Wartungsaufgaben für jeden Drucker.
---

Jeder Drucker hat eine Aufgabenliste. Eine Aufgabe ist fällig, sobald **eine** ihrer Grenzen erreicht ist: Druckstunden, Anzahl
Drucke oder Tage. Eine Grenze von 0 wird ignoriert.

## Empfohlene Aufgaben

| Aufgabe | Fällig alle |
| --- | --- |
| Achsen schmieren | 100 Druckstunden |
| Düse reinigen | 50 Druckstunden |
| Riemenspannung prüfen | 200 Druckstunden |
| Druckbett reinigen | 20 Drucke |
| Lüfter reinigen | 90 Tage |

Aktivieren Sie sie einzeln oder alle auf einmal, oder fügen Sie eigene mit Notizen hinzu.

## Wenn eine Aufgabe fällig ist

Die Aufgabe wird am Drucker und auf der Seite **Wartung** als *Fällig* markiert, und es wird einmal eine Benachrichtigung
gesendet. Klicken Sie auf **Erledigt**, um sie zurückzusetzen, mit optionaler Notiz. Der Verlauf speichert Datum, Notiz und die
Nutzung zu diesem Zeitpunkt.

Eine fällige Aufgabe hält den Drucker nie an. Um einen Drucker während der Arbeit aus der Warteschlange zu nehmen, nutzen Sie
den [Wartungsmodus](/de/docs/guide/queue#maintenance-mode).
