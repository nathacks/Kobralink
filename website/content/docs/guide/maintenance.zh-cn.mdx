---
title: 维护
description: 每台打印机的预防性维护任务。
---

每台打印机都有一个任务列表。只要达到**任一**限制，任务就到期：打印小时数、打印次数或天数。设为 0 的限制会被忽略。

## 推荐任务

| 任务 | 周期 |
| --- | --- |
| 润滑各轴 | 100 打印小时 |
| 清洁喷嘴 | 50 打印小时 |
| 检查皮带张力 | 200 打印小时 |
| 清洁热床 | 20 次打印 |
| 清洁风扇 | 90 天 |

可以逐个启用或一次全部启用，也可以添加带备注的自定义任务。

## 任务到期时

任务会在打印机和**维护**页面上标为*到期*，并发送一次通知。点击**完成**即可重置，可附带备注。历史会记录日期、备注和当时的使用量。

到期任务不会让打印机停止。维护期间要把打印机移出队列，请使用[维护模式](/zh-cn/docs/guide/queue#maintenance-mode)。
