发送到 Kobralink 的每个 G-code（来自 OrcaSlicer 或浏览器）都保存在**所有打印机共用的一个文件库**中。只接受 `.gcode` 和
`.bgcode` 文件。

## 页签

| 页签 | 内容 |
| --- | --- |
| 全部 | 所有已保存的文件 |
| 网页 | 从浏览器上传、尚未验证的文件 |
| 打印机 | 打印机内部存储中的文件 |
| 历史 | 过去的打印 |
| 延时摄影 | 录制的视频 |

## 添加文件

把一个或多个文件拖到卡片上，或点击浏览。文件也可以来自 OrcaSlicer 或任何 Moonraker 客户端。

从浏览器上传的文件并非由 OrcaSlicer 为这台打印机切片，因此 Kobralink 会在打印前要求确认。你可以在
[打印机设置](/zh-cn/docs/administration/printer-settings#printing)中关闭**网页上传时警告**。

## 文件卡片

每张卡片显示缩略图、预计时间、各颜色所需用量的耗材、上次打印和[预计成本](/zh-cn/docs/guide/statistics#costs)。

**预览**以 3D 逐层打开模型。打印时，*跟随*让视图停留在当前层，并按打印机每秒报告的真实位置显示喷嘴。打印头采用你的机型外观（Kobra X、Kobra 3、Kobra 3 V2、Kobra 3 Max 和 Kobra S1，其他机型为 Kobra 4），**显示打印头**按钮可将其隐藏或重新显示。打印头与打印机实时同步：顶部料管显示已装载耗材的颜色，风扇按实际转速转动，Kobra X 的屏幕显示当前使用的通道编号。模型使用实际所用槽位的颜色：从 Kobralink 启动时选择的槽位，否则为打印过程中喷嘴实际打印的槽位。喷嘴会挤出一滴当前装载耗材颜色的料滴。`.bgcode` 文件不支持预览。显示的平台就是打印机的打印板，尺寸与实物一致；左上角的菜单可在 **Anycubic 官方** 打印板、普通的 **纹理 PEI** 板和 **无（网格）** 之间切换，选择会按打印机分别保存：模型位于切片时的位置，打印头可以移出平台，就像机器调平探测或停靠时一样。

## 打印机存储

**打印机**页签列出打印机自身存储中的文件。你可以打印或删除它们，并查看切片软件生成的预览。在这里删除文件不会把它从 Kobralink
中移除。

- 打印机只列出最新的文件（Kobra 4 最多 256 个）。
- *测试模型*是打印机自带的示例文件，无法删除。

要自动释放存储，请在打印机设置中开启**打印后从打印机删除**。
