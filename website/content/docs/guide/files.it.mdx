Ogni G-code inviato a Kobralink, da OrcaSlicer o dal browser, è conservato in **una sola libreria per tutte le stampanti**. Sono
accettati solo file `.gcode` e `.bgcode`.

## Schede

| Scheda | Contenuto |
| --- | --- |
| Tutti | Tutti i file salvati |
| Web | File caricati dal browser e non ancora verificati |
| Stampante | File nella memoria interna della stampante |
| Cronologia | Stampe passate |
| Timelapse | Video registrati |

## Aggiungere file

Trascina uno o più file sulla scheda, oppure fai clic per sfogliare. I file possono arrivare anche da OrcaSlicer o da qualsiasi
client Moonraker.

Un file caricato dal browser non è stato slicato per questa stampante da OrcaSlicer, quindi Kobralink chiede conferma prima di
stamparlo. Puoi disattivarlo con **Avvisa sui caricamenti web** nelle
[impostazioni della stampante](/it/docs/administration/printer-settings#printing).

## Schede dei file

Ogni scheda mostra la miniatura, il tempo stimato, i filamenti con la quantità necessaria per colore, l'ultima stampa e il
[costo stimato](/it/docs/guide/statistics#costs).

**Anteprima** apre il pezzo in 3D, strato per strato. Durante una stampa, *Segui* mantiene la vista sullo strato attuale e mostra l'ugello
nella sua posizione reale, letta dalla stampante ogni secondo. La testina corrisponde alla vostra macchina (Kobra X, Kobra 3, Kobra 3 V2, Kobra 3 Max e Kobra S1, o Kobra 4 per le altre);
il pulsante **Mostra la testina di stampa** la nasconde o la mostra di nuovo. Segue la stampante in diretta: i tubi in alto prendono il colore dei filamenti
caricati, la ventola gira alla sua velocità reale e il display della Kobra X mostra il numero del canale in uso.
Il pezzo prende i colori degli slot realmente usati: quelli scelti all'avvio da Kobralink, altrimenti quelli che l'ugello
stampa durante la stampa. Una goccia del colore del filamento caricato esce dall'ugello. Le
anteprime non sono disponibili per i file `.bgcode`. Il piatto mostrato è il piano della stampante nelle sue dimensioni reali; il menu in alto a sinistra passa dal foglio **Anycubic ufficiale** a un semplice foglio **PEI testurizzato** o a **Nessuno (griglia)**, e la scelta viene salvata per ogni stampante: il pezzo è dove è stato sezionato, e la testina può uscirne, come sulla macchina quando tasta o si parcheggia.

## Memoria della stampante

La scheda **Stampante** elenca i file salvati sulla stampante stessa. Puoi stamparli o eliminarli e vedere l'anteprima creata
dallo slicer. Eliminare un file qui non lo rimuove da Kobralink.

- La stampante elenca solo i suoi file più recenti (al massimo 256 sulla Kobra 4).
- I *Modelli di prova* sono i file di esempio forniti con la stampante. Non si possono eliminare.

Per liberare la memoria in automatico, attiva **Elimina dalla stampante dopo la stampa** nelle impostazioni della stampante.
