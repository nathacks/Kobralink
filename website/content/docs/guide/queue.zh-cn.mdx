---
title: 打印队列
description: 所有打印机共用一个队列，带兼容性和耗材检查。
---

Kobralink 只有**一个所有打印机共用的队列**。每个文件会交给第一台空闲且兼容的打印机。

## 添加文件

在打印窗口中使用**加入队列**，并选择目标：

- **此打印机**
- **任意打印机**
- **一个标签**：任何带有该标签的打印机（标签在打印机的[档案](/zh-cn/docs/administration/printer-settings#profile)中设置）

如果没有任何打印机能打印某个文件，Kobralink 会拒绝它，并说明每台打印机的原因。

## 兼容性 [#compatibility]

| 检查 | 规则 |
| --- | --- |
| 目标 | 打印机是所选的那台，或带有所选标签 |
| 型号 | 文件是为该型号切片的 |
| 喷嘴 | 文件的喷嘴与已安装的喷嘴一致，或与该型号的标准喷嘴一致 |
| 尺寸 | 模型能放进打印体积 |
| 材料 | 你的库存中有这种材料的料卷 |
| 颜色 | 仅作提示，从不阻止 |

你的库存 = Spoolman（或本地库存）加上槽位中已装载的耗材。

## 任务为什么在等待 [#why-an-item-waits]

| 原因 | 含义 |
| --- | --- |
| 没有打印机能接 | 不存在兼容的打印机 |
| 打印机忙碌 | 正在打印 |
| 待清理热床 | 上一个模型需要取下并评价 |
| 打印机维护中 | 打印机已移出队列 |
| 打印机离线 | Kobralink 无法连接它 |
| 等待耗材 | 已装载的材料不匹配，或料卷不够 |
| 就绪，请手动开始 | 一切正常，自动开始已关闭 |

等待耗材的任务不会阻塞后面的任务。它第一次被跳过时你会收到通知。

## 清理热床 [#clearing-the-bed]

打印结束后，打印机会等待你确认热床已清空：

- **已清理，质量良好**：释放打印机。
- **质量不合格**：把这次打印记为失败（若尚无原因则记为*质量不合格*），并把文件重新放到这台打印机队列的最前面。

取消或失败的打印始终会等待你确认，即使关闭了确认。

## 自动开始 [#automatic-start]

在[打印机设置](/zh-cn/docs/administration/printer-settings#printing)中为每台打印机设置：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 自动开始下一个文件 | 关 | 下一个文件自动开始 |
| 确认热床已清空 | 开 | 每次打印后等待你的确认 |
| 开始前等待 | 15 秒 | 开始前倒计时，可取消 |
| 灯光触发 | 关 | 在打印机本身上确认 |

<Callout type="error" title="不确认就自动开始">
    只有在热床能自行清空（有顶出装置）时才关闭*确认热床已清空*。否则下一次打印会直接打在上一个模型上。
</Callout>

### 灯光触发 [#light-trigger]

在打印机屏幕上 **20 秒内按 3 次**灯光按钮：热床即确认已清空，下一个文件立即开始，不倒计时。开启灯光触发也会同时开启自动开始。

## 维护模式 [#maintenance-mode]

**维护模式**会把打印机移出队列，直到你结束它。如果自动开始已开启，结束维护模式可能会启动下一个文件。
