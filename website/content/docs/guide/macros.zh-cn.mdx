---
title: 宏
description: 一键执行的动作序列。
---

宏是一组按顺序在打印机上执行的动作（最多 30 个）。宏不是 G-code：打印机在局域网下不接受原始 G-code。

在**设置 → 宏**中创建，在打印机的**宏**卡片中运行。

## 动作

| 动作 | 参数 |
| --- | --- |
| 温度 | 喷嘴 0–320 °C，热床 0–120 °C |
| 等待温度 | 喷嘴和/或热床，最多 15 分钟 |
| 风扇 | 0–100 % |
| 灯光 | 开或关 |
| 速度 | 静音、标准或运动 |
| 回零 | 全部、XY 或 Z |
| 移动 | X、Y 或 Z，任一方向最多 300 mm |
| 关闭电机 | |
| 耗材 | 为某个槽位进料或退料 |
| 烘干 | 30–80 °C，10–1440 分钟 |
| 停止烘干 | |
| 等待 | 最多 600 秒 |

每台打印机同一时间只运行一个宏。

## 示例：为 PLA 预热

1. 温度：喷嘴 210 °C，热床 60 °C
2. 等待温度：热床 60 °C
3. 灯光：开

## 从其他程序调用宏

宏名称可以在 [Moonraker](/zh-cn/docs/integrations/moonraker) 端口上作为 G-code 命令使用。大小写、空格和连字符不影响：

```bash
curl -X POST "http://192.168.1.20:7125/printer/gcode/script?script=PREHEAT_PLA"
```

宏也可以由[自动化](/zh-cn/docs/guide/automations)和 [AI 助手](/zh-cn/docs/integrations/mcp)运行。
