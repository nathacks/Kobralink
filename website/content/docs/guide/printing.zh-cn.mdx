## 打印窗口

打印文件时，以及上传之后（包括从 OrcaSlicer *发送并打印*），都会打开这个窗口。

1. 在预览中**检查模型**。
2. **映射耗材**：G-code 的每个通道对应一个槽位。Kobralink 会推荐兼容的槽位，并在材料不匹配时提醒。
3. **检查用量**：窗口会把所需耗材与所分配料卷的剩余量比较（足够、刚好、不足）。如果料卷不够，你必须确认才能继续打印。
4. **跳过**你不想打印的**对象**。
5. **选择选项**，然后打印、加入队列或定时。

没有已装载的槽位时，打印机使用打印头中的耗材。

### 选项

| 选项 | 作用 |
| --- | --- |
| 自动调平 | 打印前探测热床 |
| 振动补偿 | 打印前测量共振以减少振纹 |
| 流量校准 | 打印前测量挤出流量 |
| 录制延时摄影 | 见[摄像头](/zh-cn/docs/guide/camera#timelapses) |
| 失败检测（AI） | 见[失败检测](/zh-cn/docs/guide/failure-detection) |

只有当打印机报告支持时，才会显示这三项校准选项。它们的默认值在[打印机设置](/zh-cn/docs/administration/printer-settings#printing)中。

## 打印过程中

打印在校准之后开始；卡片会显示当前步骤（加热、调平、流量校准…）。你可以暂停、继续、取消，修改速度、温度和风扇，以及跳过对象。

**跳过对象**会从当前层起不再打印所选对象，本次打印无法撤销。G-code 必须包含对象标记（OrcaSlicer 中的**标记对象**）。

打印机自行暂停时，常见代码的原因会以你的语言显示。其他代码显示打印机自己的消息。

## 定时打印

**定时**会在选定的日期和时间开始打印。到时：

- 如果打印机空闲，打印开始
- 如果打印机忙碌、离线、处于维护或在等待清理热床，文件会进入**队列最前面**
- 如果 Kobralink 当时未运行，它恢复后仍会开始打印，除非已延迟超过一小时；此时该定时会被丢弃

定时打印列在队列的**已计划**页签中。你会收到包含结果的通知。

<Callout type="warn">定时开始前请确认热床是空的。</Callout>
