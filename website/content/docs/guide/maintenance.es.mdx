---
title: Mantenimiento
description: Tareas de mantenimiento preventivo de cada impresora.
---

Cada impresora tiene una lista de tareas. Una tarea vence en cuanto se alcanza **uno** de sus límites: horas de impresión,
número de impresiones o días. Un límite en 0 se ignora.

## Tareas recomendadas

| Tarea | Cada |
| --- | --- |
| Lubricar los ejes | 100 horas de impresión |
| Limpiar la boquilla | 50 horas de impresión |
| Revisar la tensión de las correas | 200 horas de impresión |
| Limpiar la cama | 20 impresiones |
| Limpiar los ventiladores | 90 días |

Actívalas una a una o todas a la vez, o añade las tuyas con notas.

## Cuando vence una tarea

La tarea se marca como *Pendiente* en la impresora y en la página **Mantenimiento**, y se envía una notificación una vez. Haz
clic en **Hecho** para reiniciarla, con una nota opcional. El historial guarda la fecha, la nota y el uso en ese momento.

Una tarea pendiente nunca detiene la impresora. Para sacar una impresora de la cola durante el trabajo, usa el
[modo mantenimiento](/es/docs/guide/queue#maintenance-mode).
