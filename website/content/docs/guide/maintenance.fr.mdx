---
title: Maintenance
description: Les tâches de maintenance préventive de chaque imprimante.
---

Chaque imprimante a une liste de tâches. Une tâche est due dès qu'**une** de ses limites est atteinte : heures d'impression,
nombre d'impressions ou jours. Une limite à 0 est ignorée.

## Tâches recommandées

| Tâche | À faire toutes les |
| --- | --- |
| Lubrifier les axes | 100 heures d'impression |
| Nettoyer la buse | 50 heures d'impression |
| Vérifier la tension des courroies | 200 heures d'impression |
| Nettoyer le plateau | 20 impressions |
| Nettoyer les ventilateurs | 90 jours |

Activez-les une par une ou toutes à la fois, ou ajoutez les vôtres avec des notes.

## Quand une tâche est due

La tâche est marquée *À faire* sur l'imprimante et dans la page **Maintenance**, et une notification est envoyée une fois.
Cliquez sur **Fait** pour la remettre à zéro, avec une note facultative. L'historique garde la date, la note et l'usage à ce
moment-là.

Une tâche due n'arrête jamais l'imprimante. Pour sortir une imprimante de la file pendant l'intervention, utilisez le
[mode maintenance](/fr/docs/guide/queue#maintenance-mode).
