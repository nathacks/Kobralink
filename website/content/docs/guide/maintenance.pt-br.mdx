---
title: Manutenção
description: Tarefas de manutenção preventiva de cada impressora.
---

Cada impressora tem uma lista de tarefas. Uma tarefa vence assim que **um** dos seus limites é atingido: horas de impressão,
número de impressões ou dias. Um limite em 0 é ignorado.

## Tarefas recomendadas

| Tarefa | A cada |
| --- | --- |
| Lubrificar os eixos | 100 horas de impressão |
| Limpar o bico | 50 horas de impressão |
| Verificar a tensão das correias | 200 horas de impressão |
| Limpar a mesa | 20 impressões |
| Limpar as ventoinhas | 90 dias |

Ative-as uma a uma ou todas de uma vez, ou adicione as suas com anotações.

## Quando uma tarefa vence

A tarefa é marcada como *Vencida* na impressora e na página **Manutenção**, e uma notificação é enviada uma vez. Clique em
**Feito** para zerá-la, com uma anotação opcional. O histórico guarda a data, a anotação e o uso naquele momento.

Uma tarefa vencida nunca para a impressora. Para tirar uma impressora da fila durante o serviço, use o
[modo manutenção](/pt-br/docs/guide/queue#maintenance-mode).
