---
title: Einschränkungen
description: Was der Drucker im LAN nicht anbietet.
---

Kobralink kann nur, was das LAN-Protokoll des Druckers anbietet.

| Nicht verfügbar | Detail |
| --- | --- |
| Roher G-Code | Konsolenbefehle werden nicht gesendet, siehe [G-Code-Skripte](/de/docs/integrations/moonraker#g-code-scripts) |
| Freie Prozentwerte für Geschwindigkeit und Fluss | Nur drei Geschwindigkeitsmodi; keine Flussregelung |
| Live-Position | Z wird aus den Schichten geschätzt |
| Z-Offset-Befehl | |
| Firmware-Update | Den Bildschirm des Druckers verwenden |
| Druckereigene KI-Erkennung | Kobralink nutzt [seine eigene](/de/docs/guide/failure-detection) |
| Druckereigener Zeitraffer | Kobralink nimmt [seinen eigenen](/de/docs/guide/camera#timelapses) auf |
| Anycubic-Cloud | Der LAN-Modus trennt den Drucker vom Konto |
| Ein zweiter LAN-Client | Der Drucker akzeptiert eine Sitzung |
| Mehr als 256 aufgelistete Dateien | Beim Kobra 4 beobachtet |
| 3D-Vorschau von `.bgcode` | |
