---
title: Limitaciones
description: Lo que la impresora no ofrece por LAN.
---

Kobralink solo puede hacer lo que ofrece el protocolo LAN de la impresora.

| No disponible | Detalle |
| --- | --- |
| G-code en bruto | Los comandos de consola no se envían, ver [Scripts G-code](/es/docs/integrations/moonraker#g-code-scripts) |
| Porcentajes libres de velocidad y flujo | Solo tres modos de velocidad; sin control de flujo |
| Posición en directo | Z se estima a partir de las capas |
| Comando de desplazamiento Z | |
| Actualización del firmware | Usa la pantalla de la impresora |
| Detección IA propia de la impresora | Kobralink usa [la suya](/es/docs/guide/failure-detection) |
| Timelapse propio de la impresora | Kobralink graba [el suyo](/es/docs/guide/camera#timelapses) |
| Nube de Anycubic | El modo LAN desvincula la impresora de la cuenta |
| Un segundo cliente LAN | La impresora acepta una sola sesión |
| Más de 256 archivos listados | Observado en la Kobra 4 |
| Vista 3D de `.bgcode` | |
