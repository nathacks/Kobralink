你需要 Docker 和 Docker Compose，运行在与打印机同一网络的机器上。镜像
[`nathacks/kobralink`](https://hub.docker.com/r/nathacks/kobralink) 支持 linux/amd64 和 linux/arm64。

<Steps>
<Step>

### 下载文件

```bash
mkdir kobralink && cd kobralink
curl -fsSLO https://raw.githubusercontent.com/NatHacks/Kobralink/main/infra/docker-compose.prod.yml
curl -fsSL https://raw.githubusercontent.com/NatHacks/Kobralink/main/infra/.env.example -o .env
```

</Step>
<Step>

### 设置地址

编辑 `.env`，把 `BETTER_AUTH_URL` 设为你在浏览器中输入的 URL：

```bash title=".env"
BETTER_AUTH_URL=http://192.168.1.20:7100
TZ=Asia/Shanghai
```

登录与这个地址绑定。如果还会通过其他地址打开 Kobralink，请把它加入 `KOBRALINK_EXTRA_ORIGINS`。`TZ` 设置定时自动化和每日统计
使用的时区（否则为 UTC）。

</Step>
<Step>

### 启动

```bash
docker compose -f docker-compose.prod.yml up -d
```

打开 `http://<主机>:7100`，按照[首次启动](/zh-cn/docs/getting-started/first-run)操作。

</Step>
</Steps>

<Callout type="warn" title="立即创建你的账号">
    第一个创建的账号会成为管理员。请在让 Kobralink 可以从外网访问之前创建它。
</Callout>

## 端口 [#ports]

| 端口 | 用途 |
| --- | --- |
| `7100` | 控制台、API、MCP 服务器 |
| `7125`–`7140` | Moonraker，每台打印机一个端口（16 台打印机） |

Kobralink 分配 Moonraker 端口没有上限（`7125`、`7126`…），但 compose 文件只发布 `7125-7140`。从第 17 台打印机起，请扩大范围：

```yaml title="docker-compose.prod.yml"
ports:
  - "${KOBRALINK_BIND:-0.0.0.0}:${KOBRALINK_PORT:-7100}:7100"
  - "${KOBRALINK_BIND:-0.0.0.0}:7125-7224:7125-7224"
```

在 Linux 上也可以改用 `network_mode: host` 并删除 `ports:` 块。此时 `KOBRALINK_BIND` 不再生效：所有端口在所有网卡上监听。

## 数据

数据库、G-code 文件、延时摄影和会话密钥保存在 `kobralink-data` 卷中，挂载于 `/data`。参见[备份](/zh-cn/docs/administration/backup)。

## 使用指定版本

`docker-compose.prod.yml` 使用 `nathacks/kobralink:latest`。要固定版本，修改它的 `image:` 行：

```yaml title="docker-compose.prod.yml"
image: nathacks/kobralink:1.1.0
```

发布的标签为 `<版本>`、`<主版本>.<次版本>` 和 `latest`。

## 从源码构建

```bash
git clone https://github.com/NatHacks/Kobralink.git
cd Kobralink/infra
cp .env.example .env
docker compose up -d --build
```
